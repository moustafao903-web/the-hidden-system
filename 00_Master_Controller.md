# 00_Master_Controller

## Purpose
Coordinate the full book production system from idea to final publishing assets.

## Core Goal
Transform one book idea into a complete Amazon-ready publishing package using connected engines.

## System Flow
1. Title Engine
2. Outline Engine
3. Cover Engine
4. Keywords Engine
5. Writing Engine
6. Author Intro Engine
7. Amazon Preview Engine
8. Description Engine
9. Marketing Controller
10. Formatting Engine

## Inputs
- Book idea
- Target reader
- Core promise
- Market angle
- Series position

## Outputs
- Final title
- Final outline
- Cover brief
- Keyword set
- Manuscript draft
- Author intro
- Preview pages
- Description
- Marketing decision
- Formatting checklist

## Rules
- One engine at a time
- No engine handles tasks outside its role
- Every output becomes input for the next engine
- Keep the system modular and scalable

## Exit Criteria
The system is complete when the book is ready for Amazon publishing.
